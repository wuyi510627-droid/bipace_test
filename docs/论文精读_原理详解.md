# 一、信用分配(CA)主线

**共同背景**:长时序 agent 走几十步,**只有终点一个成败信号**。要把这个信号"分摊"到每一步 = credit assignment。难点:成功轨迹里有冗余绕路(不该全奖),失败轨迹里有关键好步(不该全罚)。下面每篇都是"怎么把这个信号分得更细"的不同答案。

## GiGPO(你的直系起点,2505.10978)
- **原理**:把所有轨迹里**完全相同的状态**归成一堆(anchor 状态精确匹配),堆内比较不同动作的回报——某动作高于堆内平均 = 立功。不需要 critic。
- **一句话**:靠"同状态会重复出现"造出比较组,组内比动作。
- **死穴**:依赖状态精确重复;长程后期状态越来越不重复 → 组越来越空。后面所有人都在补这个洞。

## BiPACE(你的软分组正主,2606.25556)
- **原理两半**:
  - **BiGPO**:不再要求状态字面相同,而是取 **actor 自己的隐状态**(final prompt token,第 −8 层,L2 归一)、用**朴素 cosine 距离**(1−u·v)贪心聚类(阈值 ε)。"处理起来一样"的观测,在深层表示里会自然聚拢,不管表面文字。→ 把 GiGPO 的"精确匹配"升级成"行为近似等价"。
  - **PACE**:簇内再按动作拆开,算 Q̂(s,a)−V̂(s)(同伴基准的反事实)——解决"同状态不同动作,基准却一样"的问题。
- **对你**:cosine 是朴素的(不是学出来的度量),所以你的 cosine 诊断对它忠实。**它亲口留 future work:压缩进 memory 模块后哈希失效 = 你的立足点。**

## HGPO(你的自适应加权正主,2602.22817)
- **原理**:用 **k 步上下文算子**造**层级**分组——共享 k 长历史的步骤归一组,k 越大组越小越精,层层嵌套 G₀⊇G₁⊇…⊇G_K;各层优势加权求和 A=Σ w_k A_k。
- **关键**:它现在的权重是**死的**幂律 w_k=(k+1)^α/Σ,**不是自适应**。所以"按不确定性自适应加权"是它自己留的 future work(而且它承认"在摘要式 memory 上工作得很差")。
- **对你**:你创新②(用保真度当不确定性加权)正好填这个空;但注意用**保真度**而非 EMPG 的**熵**。

## GraphGPO(头号碰撞,已录 ICML26,2605.26684)
- **原理**:把同任务所有轨迹叠成**一张状态转移图**(节点=状态,边=动作转移)。用全图信息估"每个状态离目标多远",再按"这一步是否缩短了到目标的距离"给每条边分信用——**失败轨迹里推动进展的步也能得正分,成功轨迹里绕路的步不会盲目得奖**。仍不用 critic。
- **死穴**:节点靠**精确匹配**("identical states 合并"),且**只留最近2步**回避长记忆、**完全不压缩**。→ 一压缩就失效。

## G2PO(2606.22995)/ GEPO(2510.26270)—— 图-CA 红海补全
- **G2PO**:GraphGPO 的近亲。加了 **edge-centric TD**(δ=V(下个状态)−V(当前状态))做全局标准化。节点仍**精确匹配**,不压缩。
- **GEPO**:关键区别——节点用 **Sentence-BERT cosine(阈值0.9)软合并**,信用来自**图中心性**(Brandes 算法)。→ **"软节点建图"这个坑被它占了**,但它仍处理 full observation、不压缩。
- **合起来**:图-CA 的"精确/软""节点/边"格子全填满了,唯一没填的还是"压缩 memory"。

## HPO(隐形碰撞,复旦,29-工作3)
- **原理**:把 (状态,动作) 用**独立编码器投到低维"意图空间"**;把"当前策略分布"和"只由成功轨迹构成的后见(hindsight)分布"在意图空间里用 **Wasserstein 距离**对齐,对齐产生的 Kantorovich 势就是每步优势。
- **精髓(理论)**:在巨大的离散语言动作空间,逐点比(KL/重要性比)方差可无界;**在意图空间做语义聚合 + Wasserstein,方差被度量直径 D²/4 界住**。这是"软聚合能降信用方差"的**正式证明**。
- **对你**:它已把"表示空间软聚合降方差"连理论做完了——你不能再靠"软聚合"当卖点,只能靠"压缩/memory"限定。但它在**原始 (s,a)**、不碰压缩。

## BEACON(SOTA baseline,浙大,29-工作4)
- **原理**:用**里程碑探测器 Φ**(环境提供的子目标完成信号:ALFWorld 捡起/加热物体等)把轨迹切成**段**;段内做时序奖励塑形(越接近里程碑给分越高,γ=0.95);优势**双尺度** = 轨迹级(GRPO) + 段级(只在"到达同一里程碑"的轨迹间比),Â=A^traj+λ·A^seg。
- **精髓**:不靠"状态重复"(GiGPO 命根),靠**任务自带的里程碑结构**定分组边界。ALFWorld Long 92.9%,碾压 GiGPO。
- **对你**:实验绕不开的强 baseline;它的"里程碑=历史充分统计量"是**手工拍的压缩假设**,你可问"没里程碑/必须压时怎么办"。

## EMPG(占"不确定性加权",字节,29-工作5)
- **原理**:策略梯度幅度天然和熵耦合 → 自信对的更新太小、不确定的更新太大。EMPG 按**步级熵**重标定:放大"自信且对"、重罚"自信且错"、衰减"不确定";再加"未来清晰度奖励"鼓励走向低熵状态。
- **对你**:它把"用不确定性(熵)调制信用"占了。你创新②必须用**保真度**而非熵来区别。

## ∆Belief-RL(占"内在奖励",Tübingen,29-工作2)
- **原理**:每轮问模型"秘密是不是 X",取它给正确答案的概率 b_t;**信念变化** ∆Belief=log(b_t/b_{t-1}) 当稠密内在奖励——信念朝答案靠拢的动作 = 有信息价值。不用额外 critic。
- **对你**:它占了"用内在信念做 CA";但**算信念需要知道答案**,所以没真甩掉可验证奖励。你指望的"无可验证奖励"逃生口被它占了大半。

# 二、Memory 压缩主线(folder 30 关键篇)

**共同点(=你的空档)**:下面这些压缩,目标全是"压完还能检索/答题/拿奖励",**没有一篇为"压完还能把信用分对"去压**。

## Mem-T(北大,30-工作21)
- **原理**:分层记忆(事实/经验/工作/原始)。retrieval 阶段构造**记忆操作树(MoT)**,分支 rollout;给每个节点稠密奖励 R(v)=合法性·(α·证据密度+表现);再用 **hindsight credit assignment 把树的效用回传到"源记忆项"**,监督"该建/删哪条记忆"。
- **精髓**:把"给记忆记功"做成了树上的信用回传。**但信号是 QA 的 F1+证据命中,场景是问答,不是 agentic 动作信用。**

## MemoPilot(北大,30-工作15)
- **原理**:把"记忆更新"当多轮 MDP,用**多轮 GRPO**训一个记忆模型,给冻结玩家当外挂;逐轮奖励+轮级优势。发现"Full History 反而更差 → 需要 selective memory",即**用 RL 学会压掉噪声、只留有用**。
- **对你**:它已经在"用 credit 学压缩"了(博弈场景)。你 C 方案要和它划清界限。

## RGMem(30-工作8)⭐ B 的邻居,必读
- **原理**:借**重整化群(RG)**的多尺度思想——把长对话记忆做成多尺度演化:情景→语义事实→用户洞见,经**分层粗粒化、阈值更新、重标度**,快变证据与慢变特质分开。
- **对你(B)**:"多尺度/多分辨率粗粒化"的壳它有了,**但驱动是个性化/检索,不是价值失真**。读它确认这个壳没被"信用"填过。

## Memora(30-工作23)⭐ B 的邻居,必读
- **原理**:结构上平衡**抽象 vs 具体**——primary abstractions 索引具体值、cue anchors 扩检索入口;证明标准 RAG 和 KG 记忆都是它的特例。
- **对你(B)**:"抽象-具体多分辨率"它占了,**但目标是检索相关性**。你要说清:你按"价值失真"决定抽象粒度,它按"检索"。

## Neuromem(30-工作7)
- **原理**:把记忆生命周期拆 5 维(数据结构/归一化/整合/查询构造/上下文整合)做基准。**关键结论:记忆数据结构决定质量上界;激进压缩多半只是把成本在插入与检索间搬运,对准确率增益有限。**
- **对你**:可当"压缩目标选错了"的有力引子。

# 三、外部经典(新范式 B 的理论根,重点)

## Prioritized Experience Replay(Schaul, Quan, Antonoglou, Silver, ICLR 2016)⭐⭐ B 的种子
- **原理**:经验回放不再均匀采样,而是**按 |TD-error|^α 的概率采样**——TD-error 大 = 当前价值估计在这最"错"、这条经验能纠正最多 → 优先学它;再用重要性采样权修偏。
- **为什么对 B 至关重要**:它已经在做"**按价值惊讶(TD-error)分配学习资源**"。**你要做的,是把这个原则从"回放优先级"升级成"压缩分辨率"**:TD-error/优势方差大的轨迹段 = 决策关键 = 保细节;平的段 = 狠压。同一个原则,换了作用对象。这是让 B "有根、不像凭空造"的关键引用。

## Information Bottleneck(Tishby, Pereira, Bialek 1999;Tishby & Zaslavsky 2015)⭐ B 的框架
- **原理**:把输入 X 压成表示 T,目标 min I(X;T)−β·I(T;Y)——**在"压得多狠(I(X;T)小)"和"还保住对 Y 的预测力(I(T;Y)大)"之间做最优权衡**。这就是率失真理论。
- **对 B**:把 Y 换成"信用/价值",你的"价值失真率失真压缩"就是 IB 的一个实例:**用最少比特,保住对信用最relevant 的信息**。B 的数学骨架在这。

## Bisimulation 度量四件套(支撑 A,也给 B 提供"失真"的定义)
- **Ferns, Panangaden, Precup(2004)Bisimulation Metrics for MDPs**:两状态"行为等价" ⇔ 即时奖励相同 + 转移分布(递归)等价;度量 d(s,s') 能**上界 |V(s)−V(s')|**——即"行为距离"直接控制"价值差"。
- **Castro(AAAI 2020)**:可扩展地算这种相似度。
- **DBC / Zhang et al.(ICLR 2021)Learning Invariant Representations without Reconstruction**:学一个表示,使 L2 距离 ≈ bisimulation 距离(用奖励+转移训,不重构像素)。
- **MICo(Castro et al., NeurIPS 2021)**:基于采样的状态相似度,独立耦合,更省。
- **对你**:A 直接建在这上;对 B 也有用——"价值失真"可以用 bisimulation 距离来量(行为越不等价、压掉越亏)。

## Counterfactual Credit Assignment(Mesnard et al., ICML 2021)/ RUDDER(Arjona-Medina et al., NeurIPS 2019)—— 支撑 C
- **Mesnard CCA**:用**后见(future)信息**构造一个"扣掉运气"的基准——把结果里"因为这个动作"和"因为环境走运"分开,得到低方差的反事实信用。
- **RUDDER**:用一个回报预测网络找出"哪几步真正改变了期望回报",把**延迟奖励重新分配**到这些关键步。
- **对你**:C 方案(丢了会改决策才留)可借它们把"因果必要性"量化。

## Value-Preserving State Abstraction(David Abel 一系,2019-2020)—— 支撑 B
- **原理**:把"最优价值/Q 相近"的状态聚合成一个抽象状态,使抽象后仍保住近最优行为;并给出"抽象大小 vs 价值损失"的信息论权衡。
- **对你(B)**:这是"**保住价值的压缩**"最近的理论亲戚——你的"保住信用的压缩"可以类比它、并从"价值损失界"迁移到"信用损失界"。
